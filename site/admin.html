Plugins

Un plugin créé ici apparaît aussitôt dans la boutique du site et dans l'application, tant qu'il est coché « visible ». Une nouvelle version est proposée aussitôt en mise à jour dans Onirique Central. L'image du plugin et sa démo interactive de la boutique sont fabriquées à partir du fichier .vst3 lui-même : cela demande de charger le plugin sous Windows, et se fait donc quand la version est publiée depuis l'application Onirique Central (panel admin), pas depuis cette page.

Codes promo

Un code s'entre au moment d'acheter, sur le site comme dans l'application. Il sert une fois par compte. Laisser « Plugins » vide : il vaut pour tous les plugins. Les abonnements ne prennent pas de code.

Nos réseaux

Les comptes d'ONIRIQUE, affichés dans l'en-tête (rubrique « Nos réseaux »), le menu des téléphones et le pied des pages. Une adresse complète (https://…) ; laisser vide pour ne pas afficher le réseau.

Parrainage

Chaque compte a son lien. L'ami invité a une remise sur son premier plugin ONIRIQUE ; quand il fait son premier achat payé, son parrain reçoit un code personnel, et, à chaque palier d'amis acheteurs, un plugin ONIRIQUE offert. Les récompenses ne portent que sur les plugins ONIRIQUE : les partenaires encaissent leurs ventes eux-mêmes.
