Vue d’ensemble

ONIRIQUE PITCHBOX est un éditeur de hauteur pour la voix, note par note. Le plugin reçoit la prise entière, l’analyse note par note, et la resynthétise à la lecture en gardant les formants. Une note déplacée dans l’éditeur s’entend tout de suite, sans réanalyse.

La courbe grise est ce qui a été chanté, la courbe braise ce qui sortira. Le contour fantôme derrière une note montre d’où elle vient.

1. Donner la prise au plugin

Avec ARA (Studio One, Logic Pro, Cubase / Nuendo, REAPER, Cakewalk, Mixcraft) : insère PITCHBOX comme extension ARA sur la piste, il reçoit la prise tout seul.

Sans ARA (FL Studio, Ableton Live…), le mode TRANSFER, inséré comme effet sur la piste de la voix :

  1. clique TRANSFER (le plugin est armé) ;
  2. lance la lecture sur le passage à corriger ;
  3. arrête la lecture (ou clique STOP) : le passage est analysé.

Plus rapide : glisse le fichier de la voix sur la fenêtre (WAV, AIFF, FLAC, OGG, MP3), puis lance la lecture une seconde sur le clip : le plugin retrouve où il est posé. Ensuite, il rejoue sa copie corrigée chaque fois que la tête de lecture traverse ce passage. La prise est enregistrée dans le projet avec les éditions.

Une seule prise par instance. Si le clip est déplacé ensuite, refais le transfert.

2. Éditer les notes

  • Glisser une note verticalement : la poser sur la gamme. Alt : placement libre.
  • Maintenir le clic sur une note : l’entendre tenue, corrigée (transport arrêté, mode TRANSFER).
  • Double-clic : exclure la note de la correction, pour un bend voulu.
  • MODULATION : sur les notes sélectionnées, ce qu’on garde du mouvement chanté dans la note (vibrato, attaque, dérive). 0 aplatit, 1 laisse tel que chanté.
  • Sélection multiple : Ctrl ou Maj + clic, ou un cadre tracé dans le vide.
  • UNDO / REDO / RESET : RESET efface les éditions à la main et garde les réglages globaux.

Navigation : la molette monte et descend, Maj + molette avance dans la prise, Ctrl + molette zoome dans le temps, Alt + molette en hauteur.

3. Les réglages globaux

  • AMOUNT : la force de la correction sur les notes non touchées à la main.
  • SPEED : la durée de la transition en début et fin de note. 0 donne le snap dur et audible ; 40 à 80 ms sonne comme un chanteur qui trouve sa note.
  • FORMANT : déplace l’enveloppe spectrale (la voyelle) indépendamment de la hauteur.
  • DETECT KEY : règle la gamme sur la tonalité trouvée dans la prise.
  • EXPORT MIDI : les notes telles qu’elles sonneront, dans un fichier .mid.

La correction met les notes en place sans écraser le vibrato : il reste tel que chanté, sauf si tu baisses MODULATION.

Conseils

Une correction naturelle : DETECT KEY, AMOUNT vers 70 %, SPEED 50 ms, puis retouche à la main les deux ou trois notes qui en ont besoin.

Garder un bend expressif : double-clic sur la note pour l’exclure de la correction.
