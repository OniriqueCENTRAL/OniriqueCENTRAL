Overview

ONIRIQUE BROADCAST is a Windows application that runs your mic through a real-time effects chain, then sends it to a virtual microphone you can use in Discord, OBS, games and any app that accepts a microphone. Your voice comes out processed like in a studio, everywhere.

1. The virtual microphone

Windows doesn’t let an app create an audio device on its own: BROADCAST relies on a virtual audio cable, detected automatically. VB-CABLE (free) is recommended; VoiceMeeter, Virtual Audio Cable or Hi-Fi Cable are recognised too.

  1. If no cable is installed, INSTALL VB-CABLE (FREE) does everything: download of the official pack, signature check, install, 48 kHz setup.
  2. In AUDIO ROUTING, the VIRTUAL MICROPHONE output is set to CABLE Input.
  3. In Discord, OBS or the game, choose CABLE Output as the mic (the exact name is shown, COPY button).
  • RENAME renames the virtual mic as it appears in apps.
  • SET 48 KHZ: Discord runs at 48 kHz; if the cable isn’t, the app offers to fix it.
  • Discord screen sharing: the output to the cable is opened in exclusive mode, so no PC audio capture can pick your voice back up as an echo.

2. The modules

ModuleWhat it does
ECHO GUARDListens to what the PC plays, measures the headphone or speaker leak into the mic, and holds it back while nobody speaks. Discord no longer gets an echo.
NOISE GATEUltra transparent, with look-ahead, HOLD, RANGE and LEARN, which measures the room noise and sets the threshold.
PARAMETRIC EQ6 bands, set in the live analyzer.
1176VOCALBOX’s FET compressor, with VU meter and MIX for parallel compression.
MULTIBAND4 optical bands, interactive display, per-band listening.
DE-ESSER / PLOSIVESS’s and P’s, with no latency.
SATURATIONTUBE, ANALOG or TAPE, level compensated.
LIMITERAt the end of the chain: the virtual mic never clips.

Each module has its power button (click-free fade). MUTE gives apps a clean silence, BYPASS sends the raw mic, the ON AIR light shows your voice is going out.

3. The application

  • Audio engine in SHARED / LOW LAT / EXCLUSIVE mode, AUTO or fixed buffer.
  • The clocks of the mic, the cable and the headphones are never identical: each output goes through a bridge that absorbs the drift. Constant latency, no crackles over time.
  • A device unplugged or a wake from sleep: reopened automatically.
  • Closing the window keeps the virtual mic running in the notification area (MUTE, BYPASS, monitoring, Quit from the icon); start with Windows as an option.
  • Factory presets calibrated to about −16 dBFS out: Streamer Clean, Podcast Warm, Radio Broadcast, Gaming Comms, Deep Voice, Natural Light.

Tips

First launch: INSTALL VB-CABLE, then choose “CABLE Output” as the mic in Discord, and keep Discord’s noise suppression on.

A noisy room: LEARN in the NOISE GATE, in silence for a few seconds.
