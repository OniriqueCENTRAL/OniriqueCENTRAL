Vue d’ensemble

ONIRIQUE BROADCAST est une application Windows qui fait passer ton micro dans une chaîne d’effets en temps réel, puis l’envoie vers un micro virtuel utilisable dans Discord, OBS, les jeux et toute application qui accepte un microphone. Ta voix sort traitée comme en studio, partout.

1. Le micro virtuel

Windows ne permet pas à une application seule de créer un périphérique audio : BROADCAST s’appuie sur un câble audio virtuel, détecté automatiquement. VB-CABLE (gratuit) est recommandé ; VoiceMeeter, Virtual Audio Cable ou Hi-Fi Cable sont aussi reconnus.

  1. Si aucun câble n’est installé, INSTALL VB-CABLE (FREE) s’occupe de tout : téléchargement du pack officiel, vérification de sa signature, installation, réglage en 48 kHz.
  2. Dans AUDIO ROUTING, la sortie VIRTUAL MICROPHONE est réglée sur CABLE Input.
  3. Dans Discord, OBS ou le jeu, choisis comme micro CABLE Output (le nom exact est affiché, bouton COPY).
  • RENAME renomme le micro virtuel tel qu’il apparaît dans les applications.
  • SET 48 KHZ : Discord travaille en 48 kHz ; si le câble n’y est pas, l’application le propose.
  • Partage d’écran Discord : la sortie vers le câble est ouverte en mode exclusif, aucune capture du son du PC ne peut reprendre ta voix en écho.

2. Les modules

ModuleCe qu’il fait
ECHO GUARDÉcoute ce que joue le PC, mesure la fuite du casque ou des haut-parleurs dans le micro, et la retient tant que personne ne parle. Discord ne reçoit plus d’écho.

DE-ESSER / PLOSIVESLes S et les P, sans latence.
SATURATIONTUBE, ANALOG ou TAPE, niveau compensé.
LIMITEREn fin de chaîne : le micro virtuel ne sature jamais.

Chaque module a son bouton marche (fondu sans clic). MUTE donne un silence propre aux applications, BYPASS envoie le micro brut, le témoin ON AIR montre que la voix part.

3. L’application

  • Moteur audio SHARED / LOW LAT / EXCLUSIVE, tampon AUTO ou fixe.
  • Les horloges du micro, du câble et du casque ne sont jamais identiques : chaque sortie passe par un pont qui rattrape la dérive. Latence constante, aucun craquement dans le temps.
  • Un périphérique débranché ou un réveil de veille : réouverture automatique.
  • Fermer la fenêtre laisse le micro virtuel actif dans la zone de notification (MUTE, BYPASS, écoute, Quitter depuis l’icône) ; démarrage avec Windows en option.
  • Presets d’usine calibrés à environ −16 dBFS en sortie : Streamer Clean, Podcast Warm, Radio Broadcast, Gaming Comms, Deep Voice, Natural Light.

Conseils

Premier lancement : INSTALL VB-CABLE, puis choisis « CABLE Output » comme micro dans Discord, et garde la suppression de bruit de Discord activée.

Une pièce bruyante : LEARN dans le NOISE GATE, en silence pendant quelques secondes.
